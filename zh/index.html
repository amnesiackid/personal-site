tide-guardrails — 客服聊天机器人的安全防护层

为客服聊天机器人加装的输入与输出防护：输入侧做越狱检测、话题限制和个人信息脱敏；输出侧做毒性、话题和个人信息检查，并带重新生成的循环。为了让加固前后的差异一目了然，我特意选用了移除安全对齐的 Llama 3.2 3B 作为基座模型——不加防护时它几乎什么都不拒绝。组合防护在输入侧准确率为 0.90，输出侧为 0.95，并且全部在本地运行。

TextPulse — 多语言反馈 API

一个容器化的 REST API，把非结构化的多语言客户反馈转化为结构化信号，提供单条与批量分析、主题聚合和历史记录接口。这是一次以可复现的方式扩展既有代码库的练习。

TimeGPT 与 LSTM 的时间序列预测对比

微调时间序列基础模型 TimeGPT，并用 PyTorch 自己实现了 LSTM 基线，在同一份留出数据上进行对比。LSTM 基线达到 5.63% nMSE；预处理、训练、评估和误差分析均由我独立完成。
