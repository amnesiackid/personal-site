Projects

Code and demos on GitHub.

tide-guardrails — safety layer for a support chatbot

Input and output guards around a customer-service chatbot: jailbreak detection, topic restriction, and PII redaction on the way in; toxicity, topic, and PII checks with a re-ask loop on the way out. To make the before/after legible I used an abliterated Llama 3.2 3B as the base model, which refuses almost nothing unguarded. The compound guards scored 0.90 on input and 0.95 on output, and everything runs locally.

  • Guardrails AI

TimeGPT vs. LSTM for time-series forecasting

Fine-tuned TimeGPT, a time-series foundation model, and wrote a custom LSTM baseline in PyTorch to compare against it on the same held-out data. The LSTM baseline reached 5.63% nMSE; I ran preprocessing, training, evaluation, and error analysis end to end.
